# 跨平台发文

这篇文章的写作/审稿不归这个 skill 管，那是 `wechat-article` 的事——这里只管"稿子写完之后怎么发出去"。

两个平台能力完全不对等：腾讯云开发者社区能靠浏览器自动化整套走完；微信公众号会被工具直接拦截，只能做到内容准备，发布必须用户自己动手。开工前先跟用户确认要发哪个平台，别假设两个都要发。

## 前置：加载浏览器工具

只要涉及腾讯云这条路径，第一步先批量加载工具，不要一个个 ToolSearch：

```
ToolSearch("select:mcp__claude-in-chrome__tabs_context_mcp,mcp__claude-in-chrome__navigate,mcp__claude-in-chrome__computer,mcp__claude-in-chrome__read_page,mcp__claude-in-chrome__find,mcp__claude-in-chrome__file_upload,mcp__claude-in-chrome__tabs_create_mcp,mcp__claude-in-chrome__get_page_text")
```

## 腾讯云开发者社区（可自动化）

入口：`https://cloud.tencent.com/developer/article/write-new`（用户需已在 Chrome 里登录，不要代为登录）。

1. **准备导入用的 md**：把 Jekyll frontmatter（`--- ... ---`）去掉，从正文第一个 `# 标题` 开始保留到文末，另存一份到 scratchpad 目录（临时文件，不要写进仓库、不要覆盖 `_posts/` 原文件）。
2. **导入正文**：用 `find()` 搜"导入MD 文件上传 input"拿到隐藏 file input 的 ref，直接 `file_upload({paths, ref, tabId})` 把准备好的 md 传上去。
   - **不要**直接点击可见的"导入MD"按钮——那会弹出操作系统级文件选择框，`computer` 工具截不到图也点不到，等于卡死。
3. **填标题**：点"请输入标题"输入框，输入不带下划线/文件名残留的正式标题（即正文里的那个 H1，去掉 `#`）。
4. **点右上角"去发布"**，打开发布侧栏。
5. **文章来源**：勾"原创"单选框。
6. **文章标签（必填）**：这是从平台预设标签库模糊匹配选的，**不支持自由输入自定义标签**——打字后如果提示"未找到与'XXX'相关的标签"，换个更通用的近义词再试（例："用户行为分析"搜不到，换"数据分析"能命中）。选 2～3 个跟内容最贴的。下面还有个"自定义关键词"输入框是真正自由文本，但不能替代标签这一项。
7. **摘要（必填，≤200字）**：右侧有"一键提取"按钮，会自动抓正文第一段，通常只是背景铺垫、不够概括全文论点。建议点一下看看效果，不满意就 `cmd+a` 全选摘要框、`Delete` 清空，手写一段更贴合核心论点的摘要。
   - 这个编辑器里 `triple_click` 选不中输入框全部内容，清空必须用 `cmd+a` + `Delete`，不要指望三击。
8. 专栏、封面图、评论开关、超链接开关都是可选项，没有特殊要求就保留默认值。
9. **点"确认发布"**。成功后会弹出"发布成功！文章正在审核中，审核通过前仅自己可见"——这是腾讯云的正常人工审核流程（工作日 8:00 / 非工作日 9:00 起复审），不是发布失败，不用重试。
10. 点弹窗里的"前往详情页查看"，或者用 `tabs_context_mcp` 找到新开的详情页 tab，截图或 `get_page_text` 确认标题、标签、审核状态，把详情页 URL 回报给用户。

## 微信公众号（不可自动化，只能准备内容）

**先说清楚限制**：Claude in Chrome 扩展的域名安全策略直接拦截对 `mp.weixin.qq.com` 的 `navigate` 调用，报错「This site is not allowed due to safety restrictions」。换路径、加 `token` 参数、带具体 query string 都没用，说明是整个域名级别拦的，不是登录态问题。遇到这个报错不用重试、不用换 URL 硬试，直接切到"内容准备"模式，如实告诉用户工具做不到自动发布。

能做的：把文章转换成一份贴进公众号编辑器就能用的纯文本，写到 scratchpad（不进仓库），路径给用户，或者直接在对话里贴出来：

- 去掉 Jekyll frontmatter，标题单独列出来，方便用户复制进公众号的"标题"框。
- `## 二级标题` → 换成醒目的分隔符（如 `■`）或"一/二/三"，因为微信编辑器粘贴纯 markdown 不会渲染 `#`，得提示用户粘贴后自己手动加粗这几行。
- `**加粗**` → 去掉星号留纯文字，提示用户粘贴后自己选中加粗关键句。
- `` `代码/术语` `` → 换成「」引号，微信正文不支持行内代码块。
- `[文字](链接)`→ 换成"文字 链接"纯文本平铺，微信普通粘贴不支持行内超链接。

交付之后提醒用户：标题要单独复制到标题框；正文粘贴进编辑器后，小标题加粗、封面图、原创声明这几步是微信富文本编辑器的手动操作，工具接触不到，需要用户自己点完再真正群发/发表。

## 常见坑速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 点"导入MD"后页面卡住、截图看不到弹窗 | 触发了 OS 级文件选择框 | 别点可见按钮，改用 `find` + `file_upload` 直传 |
| 标签输入后提示"未找到相关标签" | 该词不在平台预设标签库里 | 换更通用的近义词重试 |
| 摘要框 `triple_click` 选不中全部文字 | 该编辑器组件不响应三击全选 | 用 `cmd+a` 后 `Delete` |
| `navigate` 到 `mp.weixin.qq.com` 报 safety restrictions | Claude in Chrome 域名级硬拦截 | 不用重试/换URL，直接转为内容准备模式 |
| 英文文章摘要写到一半被截断在 200/200 | 摘要框限制按字符数（不是词数）算，英文比中文吃字符快得多 | 英文摘要要写得比中文短很多，写完看有没有卡在字数上限、句子有没有被腰斩 |
