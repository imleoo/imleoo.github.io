# 项目长期记忆：imleoo.github.io

- **定位**：Leoo Bai 个人作品集 + 技术博客（Jekyll / GitHub Pages），中英混排。217 篇 _posts，约 40% 含中文。
- **语言分工**：中文随笔属微信公众号/DDAD 系列，写作与审查须用 `.agents/skills/wechat-article`（反 AI 味、风格画像、ai_smell.py）；英文随笔按现有 2026 英文文笔调。两份指导文件不冲突，分别管两种语言。
- **关键坑**：macOS grep 不支持 `\x{4e00}`，查中文用 ripgrep `\p{Han}` 或 Python 扫描，否则假阴性。
- **写作红线（中文）**：不用 赋能/抓手/闭环/底层逻辑/颗粒度/降维打击；「不是X而是Y」一篇≤3 次；数字须有来源或标为作者自有后台数据；禁止"在…的今天"式开头与万能结尾。
