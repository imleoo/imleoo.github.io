# 公众号写作

这个 skill 的正向风格样本主要来自 `history/` 中 2019 年的早期作品。2025 年后的部分文章含有 AI 生成内容，只能作为待修材料或反例，不能拿来归纳作者风格。

## 核心判据

**AI 味 = 没有证据，却写得异常完整、正确和顺滑。**

这不只是词汇或第一人称问题。早期作品有时写亲历，有时直接评论技术，但都会把依据、猜测和不知道的地方摊出来。AI 稿最常见的问题反而是：编一个现场，把资料拆成整齐框架，再用无来源数字和万能结尾把文章封死。

「我」不是合格证。「我读了报告」只说明读过资料；「我部署后遇到什么错误、怎么改、结果怎样」才是亲历。没有原始材料支撑时，禁止补写朋友、同事、宠物、深夜对话、测试结果或任何第一人称经历。

## 工作流程

1. **确认选题和核心观点**——一篇只讲一个你真正在乎的点，不要话题清单式覆盖。
2. **核实素材**（硬性要求）。用 WebSearch 验证每一个数据、事件、人物引用。找不到可靠来源的数字宁可删掉，绝不编造。历史文章里 AI 味最重的《Manus 爆火背后》通篇是「准确率从 82% 骤降至 47%」「设置 128 个道德检查点」这种无来源的精确数字，这是最严重的失败。
3. **标注证据类型**——哪些是公开事实、哪些是作者推测、哪些是可证明的亲历。
4. **选定笔调并搭骨架**——按文体选结构，见 `references/style-profile.md`，不为凑结构硬拆三点、五层、七步。
5. **写初稿**。
6. **自查**——跑 `scripts/ai_smell.py`，再人工过一遍 `references/ai-smell-checklist.md`。脚本只能抓词汇和句式，抓不住视角问题，人工那关不能省。

## 两副笔调

作者有两套互不混用的笔调，历史文章里泾渭分明：

**A. 大白话技术评论**（主力）
直接切题 + 具体技术细节 + 明确判断 + 自嘲或挖苦 + 诚实的不确定。优先参考 2019 年《从猫扑看互联网发展》《摩拜服务器又双叒叕挂了》《新媒体如何玩转区块链思考》。真实体验文属于这一笔调，但不得虚构体验。

**B. 鲁迅式白话文言杂文**（做文化批评时才切换）
代表作：《养小龙虾上瘾的人，和九八年逛论坛上瘾的人，大抵是同一波》《龙头之下，铝锅之间》。用「大抵」「未尝」「仿佛」「倒像」，几乎不用口语过门和脏话。

写之前先定 A 还是 B。历史文章里这两套从不混用，混了就四不像。

## 不可违反的规则

1. **开头必须有抓手**：真实场景、公开事件、读者问题或一句明确判断，选证据最硬的那个。可以直接下结论。
   - 好：「上周二凌晨2点，我删掉了2400行Claude生成的代码。屏幕右下角还开着三个聊天窗口。」
   - 坏：「在人工智能快速发展的今天，AI编程助手正成为科技行业的新焦点。」
2. **不强制第一人称**。技术评论可以不用「我」，但不能冒充亲历，也不能用「行业正在」「我们正在迎来」代替事实。
3. **技术概念先讲机制，必要时再打比方**。比喻必须帮助理解，不能为了像作者而每两段硬塞一个。
4. **数字必须有来源**，且尽量点名机构。
5. **观点要有推理链**。可以暂时不确定，但要说清楚为什么不确定；禁止用反问句或对称平衡术逃避判断。
6. **全文升华句最多一处**。禁止每段结尾都盖个戳。禁止「只是一个开始」「还在路上」「让我们拭目以待」这类万能结尾。
7. **判断说完就停**。可以留问题、回扣标题，也可以没有结尾段；禁止为了完整感强行总结、互动和升华。
8. **黑话禁令**：赋能、抓手、闭环、底层逻辑、颗粒度、降维打击——一个都不许出现。

## 招牌手法（用，但要节制）

**「不是 X，而是 Y」**是作者最鲜明的句式，用来锚定概念边界、下核心判断。但它在历史文章里严重过载：62 篇里 25 篇用了它，《在 DDAD 里》那篇一篇用了 17 次。

**一篇最多 3 次**，只留给真正的核心判断。超了就换成别的说法。

其他手法见 `references/style-profile.md`。它们是可选工具，不是每篇必填的作者指纹；重复套用同一个手法也会产生 AI 味。

## 篇幅与节奏

从 62 篇统计出来的基线（逐篇口径，中位数 / 四分位）：

| 指标 | 基线 |
|---|---|
| 正文汉字数 | 中位 1112（P25 849，P75 1790），长文可到 4600 |
| 句子长度 | 中位 28 字（P25 22，P75 40） |
| ≤20 字的短句占比 | 中位 38% |
| 普通段落 | 平均 70 字左右 |

注意：**句子长度不判别文章好坏**。好文的句长中位从 11 字到 40 字都有（《这个假期我用 Claude Code 写了一部 70 万字的小说》11 字，《当我花30分钟让AI占领了我的树莓派》40 字），AI 味文也落在同一区间。别拿句长当质量指标。

真正起作用的是**关键转折处单句成段**，制造停顿：「现在想想真打脸。」「AI在配置AI。」「呵呵。」
