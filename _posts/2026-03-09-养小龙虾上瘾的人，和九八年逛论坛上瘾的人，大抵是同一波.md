# 养小龙虾上瘾的人，和九八年逛论坛上瘾的人，大抵是同一波

我近来总觉得，中国人虽然口口声声说自己最务实，最讲究“有没有用”，其实骨子里却并不尽然。人若真只认“有用”，便该除了吃饭睡觉赚钱之外，什么也不必做；然而事实上，许多人一旦碰见一种新鲜玩意儿，便立刻把“正事”搁在一旁，日也想，夜也想，仿佛忽然得了一个新天地，非要把心血一点一点灌进去，方才舒服。譬如近来的 OpenClaw，我看就颇有些这意思。有人装上它，接了消息，配了技能，调了提示词，本来不过是想“试试看”，谁知这一试，便仿佛旧时书生误入了青楼，不到鸡叫不肯出来。若细看这些人，再想想一九九八年前后初入互联网、深夜拨号逛论坛逛得魂不守舍的那一批，便会明白：原来竟是同一波人，不过帽子换了，癖性却一毫未改。

一九九八年前后，互联网于许多人还像一扇半开未开的门。门外的人只听得里头喧哗，既不懂规矩，也不知道究竟有什么好处，可一旦推门进去，便再难轻易出来。那时候的上网，是要听拨号声的。电话线一接上，机器便怪叫，仿佛不是在连机器，倒像是在召唤幽灵。网速慢得很，开一张图也要等，然而人心里却快得很，急着看版面，急着看有没有新帖，急着看昨日和人争论的那条回帖有了下文没有。一个 ID，一块版面，几句半生不熟的文字，便足以叫人牵肠挂肚。白日里在人群中并不出奇，夜里回到屏幕前，却忽然在另一个世界里活了过来。这正是那一代人的快乐，也是那一代人的病。

如今到了这“万物皆可智能”之世，似乎一切都更高级了：论坛没有了，或至少不复当年模样；拨号声也听不见了；人们换了名目，换了界面，换了说法。然而那股旧瘾却并未死，只是悄悄转了世。有人开始折腾 OpenClaw，名义上也很冠冕：说是提高效率，说是自动化，说是让 agent 帮自己做事。话自然不假，但若真只为效率，何以要半夜三更还盯着它的日志？何以要反复试一个技能，明明能用便罢，却偏要再改改？何以任务跑通了还不满足，还要想能不能接上新的渠道，能不能再装一门本领，能不能把这电子东西养得更聪明一些、更像回事一些？可见所谓“效率”，多半只是门面，底下真正活跃着的，还是那颗喜欢折腾、喜欢沉迷、喜欢在新世界里打窝安家的心。

这便是我所说的同一波人。他们并不是爱论坛，也并不是爱 OpenClaw 本身；他们爱的是“进入一个新世界”的感觉。论坛时代，这新世界是一个由帖子、签名档、版主、灌水、潜水构成的电子市井。你发一句话，远方就有人回；你取一个名字，便仿佛在虚空中占了一张座位；你在某块版面混久了，竟也有了熟脸，有了恩怨，有了江湖。今日折腾 OpenClaw 的人，其实也是这样。他们不是在单纯用一个工具，而是在搭一个自己的小宇宙：接上 QQ，添上技能，写一条提示词，设一个自动任务，眼见那本来冷冰冰的程序竟真的会动，会回，会去执行，心里就生出一种奇怪的快慰，仿佛不是自己在使用机器，倒像是在养一个会长本事的电子生灵。

人之所以会为这种事上瘾，我想，原因并不深奥。无非是现实世界太大，而个人太小。一个人在白日的秩序里，往往只能做极小的一颗螺丝钉，发言未必有人听，想法未必有人理，时间和精力都被切成一片一片，拿去喂给工作与生活。久而久之，人心就枯了。可论坛和 OpenClaw 这样的东西，偏偏给人造出一个可以亲手摆弄、亲自见证变化的小世界。在论坛，你发帖，便有回应；在 OpenClaw 里，你一调，它便有反应。你施加一点意志，世界就动一点。这种反馈，是最容易使人入迷的。因为人在宏大现实中常常无能为力，于是格外珍惜在微小系统里那一点近乎造物主般的掌控感。

并且，这两种沉迷还有一个极相似之处：它们都不是一锤子买卖，而是靠“反复刷新”活着的。论坛的魂，在刷新；OpenClaw 的魂，也在刷新。论坛时代的人，明知一小时未必会有新内容，却总要顺手点进去看看，仿佛不看便要错过什么天大的秘密。如今折腾 agent 的人，也明知任务未必这么快跑完，技能未必这一刻就生效，却还是要看一眼，再看一眼，像守着一炉尚未烧开的水。那种心情，与其说是等待结果，不如说是享受等待本身。人的瘾，有时并不在于得到什么，而在于总有一点将得未得的希望，在眼前晃荡。

自然，也总有人要站出来说教，说逛论坛误事，说折腾 OpenClaw是不务正业，说这些东西不过是新时代的玩物丧志。这样的话，也不能说全错。若一个人真因此废寝忘食，忘了身边活人，忘了现实里该做的事，那自然是滑稽而可怜的。然而我总疑心，世上许多看似“无用”的沉迷，恰恰是在替人保留一点活气。倘若一个人除了完成 KPI、回复消息、交付表格之外，再无任何令他眼睛发亮的东西，那才真是可怕。论坛也罢，OpenClaw 也罢，至少说明他还愿意对一个新世界发生兴趣，还愿意为一个细小的变化欢喜，还没有彻底被现实磨成一块没有棱角的石头。

所以说，养 OpenClaw 上瘾的人，与一九九八年前后初入互联网逛论坛上瘾的人，的确是同一波。他们都爱新大陆，爱试探边界，爱在虚拟之地寻找存在感；他们都容易被“回应”勾住，被“刷新”驯服，被一个一点点长出秩序的小世界收编。表面看，是时代变了：从电话线、BBS、论坛，变成了 agent、技能、自动化；其实底下那根筋，几十年都没有变过。中国人并没有比从前更理性，不过是把旧时盯帖子、等回帖的劲头，挪去盯任务、调提示词、等日志罢了。对象换了，名字换了，夜深时那一点不肯睡去的兴奋，却还是旧的。说到底，人活着若一点瘾也没有，倒未必高明；只是最好知道，自己究竟是在驾驭玩具，还是已经被玩具轻轻地、温柔地反过来养了。
