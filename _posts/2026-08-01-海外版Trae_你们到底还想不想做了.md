# 海外版 Trae，你们到底还想不想做了？

作为 Trae Pro 年费用户，我续费图的是"用上海外最新模型，效率翻倍"这句话。这几个月用下来，我只想到一个字：慢。

模型不更新是慢，响应速度是慢，官方回应用户诉求，慢得更彻底——基本等于没有。

我不是在瞎编，也不是个例。Trae 官方中文社区里就有一个帖子，直接问["国际版什么时候更新模型"](https://forum.trae.cn/t/topic/97493)，底下一堆人说已经落后好几代。GitHub 上有个 issue 标题写得更狠——["Pro 会员可用模型没有任何主流模型，官方无人响应"](https://github.com/Trae-AI/TRAE/issues/2276)。还有个 Pro+ 用户发帖，用了两周之后给国际版新收费标准下了个判断：[贵到离谱](https://forum.trae.cn/t/topic/2175)。这些都不是压箱底的老帖子，是最近才发的——说明这不是哪天服务器抽风，是常态。

以前能用的功能也在变得不能用。生成 Git commit message 这种基础到不能再基础的功能，报错报得够频繁，社区里专门有帖子反复提这条报错（[原帖](https://forum.trae.cn/t/topic/3279)），GitHub 上也有好几个 issue 是同一句话——["Git commit 内容生成异常，请稍后重试"](https://github.com/Trae-AI/TRAE/issues/2370)。甚至有社区成员自己整理了一个 [bug 和产品建议汇总帖](https://forum.trae.cn/t/topic/15888)，因为零散的吐槽已经多到没人跟得上。用户开始替官方做 bug 分类整理，这不是什么好兆头。

真正让我坐下来写这篇的，是退款这件事，或者说退款这件事的不存在。翻一翻 GitHub issue，退款申请一个接一个：有人说自己被[自动续订扣了钱，压根没主动触发过](https://github.com/Trae-AI/TRAE/issues/2039)；有人[当天被扣款当天就申请退款](https://github.com/Trae-AI/TRAE/issues/1525)；还有人因为[所在地区被限制访问模型而申请退款](https://github.com/Trae-AI/TRAE/issues/2375)。这些不是发一条、关一条的孤例，是隔几天就冒一个新的。这才是问题所在——扣错款不可怕，可怕的是没人管这个循环怎么闭上。

一个编程工具，卖的其实就是模型这一件事。模型不进步，代码质量、任务成功率、用户愿不愿意打开它而不是打开别家，全都跟着往下掉。这是唯一一个 Trae 没法靠改个 UI、调个价格页面蒙混过去的东西。核心产品掉队的时候，客服本该是"失望"和"离开"之间最后一道防线，可现在这道防线也没接住。

我想跟 Trae 说清楚：年费买的不是一句"敬请期待"，买的是跟得上时代的模型。如果海外版真不是重点了，甚至打算收缩，那就说清楚，把还在续费的用户痛痛快快退了，别让人对着邮箱等一个永远不会来的回复。你可以选择不做这条线，但不能既不更新、又不退款，把人晾在半空里。

我知道这篇火气不小。是真的火大——是一封封已读不回的退款邮件、一次次"这个版本又崩了"攒出来的。我想要的不多：一个正式、公开的说法，模型更新计划是什么，堆了几周的退款申请什么时候能走完。用户要的从来不多，就是一个说话算话。
