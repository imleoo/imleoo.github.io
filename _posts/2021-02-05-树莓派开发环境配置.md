# 树莓派开发环境配置

接上篇，准备树莓派开发环境的配置。

![](https://ask.qcloudimg.com/http-save/yehe-1158072/g3ygotoiex.png)

    买回来的树莓派一般会带一个系统，在这里我建议自己定制系统，以树莓派桌面系统为蓝本搭建开发环境。


1. 你需要准备一张 16G的高速TF卡，用以安装系统。
2. 4B取消了全尺寸的HDMI，还需要准备一个miniHDMI转HDMI的线缆来连接显示器。
3. 需要3A以上的电源，否则连接键盘鼠标再加上摄像头以后就供电不足了。
4. 读卡器 用来在电脑上写系统进去。





- 准备烧写系统


板卡及TF准备好了之后就可以去官网上下载系统及相关工具了。

1. 下载 Raspberry Pi Imager 这个在官网中就有，用来烧写镜像用的。
2. 下载Raspberry Pi OS with desktop 镜像，这个镜像带有桌面功能，但是缺少相关的软件，需要我们自己构建安装。
3. 插上读卡器，用Raspberry Pi Imager  烧写镜像 这一步很简单，1、2、3就结束了。




![](https://ask.qcloudimg.com/http-save/yehe-1158072/48bmum8uae.png)

1. 唯一需要注意的，在选择镜像的时候要选择use custom 否则你可能需要重新下一遍系统。




![](https://ask.qcloudimg.com/http-save/yehe-1158072/m24rmiqibg.png)

1. 烧写完毕，插到树莓派上就可以启动使用了。



配置环境：


1. 配置接口



![](https://ask.qcloudimg.com/http-save/yehe-1158072/e4ceweow4p.png)

- 打开摄像头，SPI，I2C、Serial Port。


            方便通过程序访问摄像头以及外部控制接口


如果还需要远程访问、以及远程管理，则把 ssh和VNC 两个服务打开，这样就可以通过远程或者远程桌面来管理了。


- 配置vim
由于树莓派内置的vim功能不全，会导致汉字乱码，以及输入混乱，需要卸掉安装一个完全的版本。
打开终端:
        输入：sudo apt-get remove vim-common

  等待删除完毕

  输入：sudo apt-get install vim

  完成了vim的配置

- 测试是否可以访问摄像头
连接摄像头至CSI接口，蓝色一面朝向USB端口
- 

![](https://ask.qcloudimg.com/http-save/yehe-1158072/73128cgy7t.jpeg)


打开终端：

                输入:raspistill -v -o test.jpg

                如果没问题，就会在界面上显示摄像头预览的窗口，等预览窗口消失后在pi目录下会生成一张test.jpg的照片。
