# 我用“龙虾”自动经营 LinkedIn 28 天，跑出了 7000%+ 增长（真实后台数据）

如果你半个月前跟我说： “你会靠一只龙虾，把 LinkedIn 的数据拉到 7000%+ 增长”，我大概率会觉得你在整活。

但这 28 天，我确实用“龙虾”做了一次**自动经营实验**，并且拿到了很硬的结果。

**这次我看的是：触达的会员（Members Reached）。** 因为点赞可以很虚，但“触达多少人”更接近真实的增长与潜在线索。

## **28 天的真实后台数据**

- 展示量（Impressions）：**3,727**（较前 28 天 **+7,829.8%**）
- 触达的会员（Members Reached）：**2,064**（较前 28 天 **+7,544.5%**）

> *结论先放这：增长不是靠“更努力”，而是靠“更可复制”。龙虾只是外壳，系统才是引擎。*

## **一个对照实验：14 天 OpenClaw vs 14 天 VibeCoding**

我不想把结论写成“凭感觉”。所以我把 28 天拆成两段对照：

- 其中 **14 天**：发 **OpenClaw** 相关内容
- 其中 **14 天**：发 **VibeCoding** 相关内容

然后我看内容榜单（Top 内容）发生了什么。

![](https://developer.qcloudimg.com/http-save/yehe-1158072/83af792f284f91e3414d99aeb943621a.png)

**结果非常清晰：**

- **Top 1、3 的是 VibeCoding 主题**
- 第 1 名获得了 **1250 展示量**
- **第二名 OpenClaw 仅有204 展示量**

这不是 OpenClaw 不好——它在国内确实很火。 但在海外语境里，VibeCoding 的受众盘子更大、跨圈层更容易，平台也更愿意把它分发给更广的人群。

## **我从这次增长里得到的 3 个发现**

### **1）LinkedIn 更像“分发系统”，不是“知识库”**

同样是技术内容：

- “工具/功能更新”往往只在小圈子里传播
- “趋势 + 场景 + 可执行动作”更容易破圈

VibeCoding 天生更像后者。

### **2）选题的“受众盘子”决定上限**

如果你的内容只有圈内人看得懂，它很难被扩散。

我的策略会变成两层：

- 用 **VibeCoding 做拉新**（扩大触达）
- 用 **OpenClaw 做承接与转化**（建立信任、引导私信、落地交付）

### **3）复利来自“栏目化”，不是“爆款化”**

这 28 天不是一篇把我送上天，而是我把输出做成了流程：

- 固定结构（开头钩子 → 3 条要点 → 结尾一句话）
- 固定节奏（发布后集中互动）
- 固定记忆锚点（龙虾让人更容易记住我）

## **一个残酷但有用的问题**

如果你也想在海外 LinkedIn 增长，建议你问自己：

**“这条内容，能让一个不认识你/不认识你的工具的人，也觉得有用吗？”**

如果答案是“能”，那它更可能被推荐。
