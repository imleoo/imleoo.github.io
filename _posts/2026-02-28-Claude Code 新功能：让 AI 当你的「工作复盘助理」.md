# Claude Code 新功能：让 AI 当你的「工作复盘助理」

最近 Claude Code 上线了一个挺有意思的新指令：`/insights`。

试用了一下，感觉像是给自己配了个「工作观察员」。

![](https://developer.qcloudimg.com/http-save/yehe-1158072/c025138f611ddf117fef71583c895835.png)

## **它到底做什么？**

简单说，就是 AI 会翻你过去 30 天的聊天记录，然后生成一份 HTML 报告。

报告里包含这几块内容：

**1. 你在做什么项目**

它会自动识别你最近在折腾的几个项目领域，比如「调试前端组件」「配置 CI/CD 流程」「写数据分析脚本」之类的，并且统计每个领域你花了多少时间。

**2. 你的工作习惯**

这部分有点像照镜子。它会分析你平时是怎么跟 Claude 对话的：

- • 你喜欢一次性把需求说清楚，还是边聊边改？
- • 你经常打断 Claude 的工作流程吗？
- • 你更倾向于让 Claude 自己探索代码库,还是手动指定文件？

**3. 哪些地方做得不错**

比如你擅长用 Claude 处理多文件修改、快速定位代码问题，或者在某个复杂项目上的协作特别高效。

**4. 哪些地方有摩擦**

这部分就比较「扎心」了。它会明确指出：

- • Claude 哪些地方理解错了你的意思
- • 代码改完之后发现有 bug
- • 你拒绝了 Claude 的某些操作
- • 环境配置问题导致任务卡住

并且会给出具体例子，比如「你在 3 次会话中都让 Claude 记得运行测试，但没有写进 CLAUDE.md 文件」。

**5. 改进建议**

包括三类：

- • **可以加进 CLAUDE.md 的规则**：比如你总是重复同样的指令，那就该把它写进项目文档里
- • **还没用过的功能**：比如 MCP 服务器、自定义技能、钩子函数等
- • **工作流优化**：比如可以尝试用无头模式跑 CI/CD，或者让 Claude 用子代理并行处理任务

**6. 未来可以试试的野路子**

针对越来越强大的 AI 模型,它会建议一些现在看起来有点「激进」的工作流,比如让 Claude 自主迭代代码直到通过所有测试。

## **它怎么做到的？**

这个功能背后有点技术含量。

它会：

1. 1. 读取你过去 30 天的所有会话记录
2. 2. 过滤掉那些太短的、内部操作的会话
3. 3. 提取每次会话的元数据（用了哪些工具、改了多少行代码、Git 提交次数等）
4. 4. 用 AI（Haiku 模型）分析每次对话，提取「维度数据」——比如你的目标达成度、满意度、遇到的摩擦类型
5. 5. 把所有数据汇总,再用不同的专门提示词生成各个板块的分析
6. 6. 最后渲染成一个交互式 HTML 报告

整个过程是本地完成的,数据不会上传到哪里。分析过的会话会被缓存,所以下次运行会快很多。

## **我的实际体验**

运行指令很简单,在 Claude Code 里输入 `/insights` 就行。

等几分钟,它会在 `~/.claude/usage-data/report.html` 生成报告。

打开之后会看到:

- • 统计数据：总会话数、消息数、工作时长、代码改动量
- • 可视化图表：每日活跃度、工具使用分布、编程语言占比
- • 详细分析：交互风格、成功案例、摩擦点、改进建议

我自己跑完发现几个问题:

- • 有些指令我在多次会话里重复说了,其实该写进项目文档
- • 一些 Claude Code 的高级功能我压根没用过
- • 我的提问方式有时候太模糊,导致 Claude 理解错了

最有意思的是「memorable moment」部分——它会从你的聊天记录里挑一个有意思的片段,比如某次特别曲折的 debug 经历,或者某句搞笑的对话。

## **适合谁用？**

如果你:

- • 经常用 Claude Code 写代码
- • 想知道自己的工作模式有没有优化空间
- • 或者单纯好奇「我到底是怎么跟 AI 协作的」

可以试试这个功能。

它不是什么革命性创新,但胜在实用——就像有个人默默观察你工作一个月,然后心平气和地跟你说:「这儿可以改改。」

不烦人,还挺管用。

**使用提示：**

- • 越频繁使用 Claude Code,生成的报告越有价值
- • 跟 Claude 对话时记得给反馈（「不错」「不对」之类的），这样它能更准确判断你的满意度
- • 建议每月跑一次,看看自己的工作模式有没有变化
